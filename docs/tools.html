Tools

Tools

Small Python scripts make, read, and check the language. They use only the standard library. The font build also needs fonttools.

Write in rings

Type Oruhi in Latin spelling. The font draws the rings. A holy word starts with a capital letter. Try Oruo or kisa Oru.

Command line

Get the source and run the tools from the folder of the project. The output below is real. A script made this page and ran each command.

git clone https://github.com/Orpheus-21/oruhi.git
cd oruhi
python3 src/cli.py --help

lookup

Find a word by its form or by its English gloss.

compose

Write Oruhi from tokens. A token is a gloss, then affix labels with hyphens. This is the translator of the language. It works word by word and it does not read English.

gloss

Read an Oruhi sentence. The tool shows the parts of each word and the gloss. It prints a note when a word has more than one reading.

number

Convert a number between base 10, base 8, and Oruhi words. The input can be digits or Oruhi words in quotes.

ring

Write text as an SVG image. Add --spiral for a spiral. Add -o file.svg to write a file.

python3 src/cli.py ring --spiral "Oruo minuni punupiha." -o prayer.svg

font

Build the font file. This command needs fonttools.

python3 -m venv .venv
.venv/bin/pip install fonttools
.venv/bin/python src/cli.py font

The check

One script checks the whole language. Run it after any change to the data.

.venv/bin/python src/check.py

The check tests these things:

  • Every word follows the syllable rules.
  • Only holy words contain the vowel o.
  • No two words share a form or a gloss.
  • Every word with every legal row of affixes gives a legal word with exactly one reading.
  • Every number from 0 to 4095 reads back to itself.
  • Every sample sentence composes and parses back to the same parts.
  • Every syllable has a glyph, and no two glyphs look the same.
  • The font builds and holds all 32 ligatures.

The limits of the translator

The tool works word by word. It cannot translate English text. It does not guess a word that is missing from the lexicon. A gloss with two words needs an underscore, such as great_empty.
