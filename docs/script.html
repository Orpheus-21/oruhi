Writing

The ring script

One ring is one syllable. The ring is the sign of zero, so the zero is in every word.

How to read one ring

A tick outside the ring names the consonant. A mark inside the ring names the vowel. A ring with no tick has no consonant. A ring with no mark is the holy vowel o.

The ring has eight places for ticks, one for each consonant. The consonants go clockwise from the top. The three stops come first, then the two nasals, then the two fricatives, and the tap comes last.

Numerals

A numeral is a ring that stands on a base line. Dots inside the ring give the digit. The ring with the base line and no dots is the digit zero.

The base line is the only difference between the numeral zero and the vowel o. A numeral has dots and no tick. A syllable has no base line.

Spacing and direction

  • A gap separates words. A small ring ends every sentence. It is a zero of the size of a dot.
  • Records and letters run in rows, from left to right.
  • Holy texts run in a spiral. The first ring is at the center. The spiral turns clockwise and grows outward.

A spiral turns each ring so that its top points away from the center. A reader follows the line of the spiral, and the rings tilt with it.

This spiral holds the Prayer of the Empty. The texts page gives the gloss.

The font

The font Oruhi Ring draws the script. It is a TrueType file: fonts/oruhi-ring.ttf.

You type the Latin spelling of a word. The font replaces each pair of letters with one ring. It does this with the standard liga feature, so every modern browser and word processor shows the rings.

  • Each syllable also has a code point in the Private Use Area, from U+E000. The syllables are in alphabetic order.
  • The digits 0 to 7 draw the numerals. The digits 8 and 9 have no glyph.
  • A period draws the small ring. A hyphen draws nothing, so teaching forms such as kisa-ka-ni show as one row.
  • Capital letters and small letters draw the same glyph.

A letter that cannot join a syllable draws nothing. The text kap shows only the ring for ka. The tools page has a box that warns you about such spellings.

How the shapes are made

Each glyph is a short list of shapes: rings, bars, polygons, and dots. One file, src/script.py, holds the list. The same list makes the SVG images on this site and the font. Because of this, the images and the font cannot differ.
